⚠️ Scientific & Statistical Distinction Notice:
  • Global Importance (MDI): Shows which variables the model relies on most frequently to split decisions across the entire training dataset.
  • Local Attribution (Tree Path Decomposition): Shows which specific measurements pushed the model towards or against a single recommendation.
  • Correlation vs. Causation: These values reflect statistical patterns learned from empirical data. They represent machine learning decision logic, not direct biological or biochemical causation.

💡 How Local Attribution Works

We implement Exact Decision Tree Path Decomposition (TreeInterpreter method) natively supported by your trained Random Forest model.

$$\text{Confidence}(\text{Class}) = \text{Base Prior Rate} + \sum_{i} \text{Contribution}_i$$
  • Base Prior Probability: The average probability of this fertilizer across all 10,000 training samples before inspecting this specific farmer's soil.
  • Positive Drivers (+): Soil features that directed tree branches towards recommending this fertilizer.
  • Negative Drivers (-): Features that reduced the likelihood of this fertilizer.
